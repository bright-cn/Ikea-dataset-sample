# # 宜家数据集示例

<h2>包含 1001 款宜家产品的示例数据集</h2>

![Ikea 数据集页眉](https://github.com/bright-cn/Ikea-dataset-sample/blob/main/Ikea-datasets.png)

一个包含 1000+ 条记录的宜家（IKEA）数据集示例。数据集使用 <b>Bright Data API</b> 提取。

<h2>Ikea 数据集中包含的部分数据字段：</h2>

* ```description```: 对宜家产品的文本描述
* ```in_stock```: 表示产品当前是否有货
* ```color```: 产品颜色或可选配色
* ```size```: 产品尺寸或可选尺寸
* ```reviews_count```: 该产品的评论总数
* ```main_image```: 产品主图的引用或链接
* ```category_url```: 产品所属类别的 URL 链接
* ```category```: 产品所属类别
* ```category_id```: 类别的唯一标识符
* ```category_tree```: 产品类别的层级结构表示
* ```rating```: 产品平均评分
* ```image_urls```: 产品图片的引用或链接
* ```designer```: 与该产品相关的设计师
* ```details```: 产品的其他详细信息
* ```brand```: 关联品牌
* ```related_products```: 与当前产品相关的产品
* ```model_number```: 产品型号
* ```video_count```: 与产品相关的视频数量
* ```videos```: 与产品相关的视频引用或链接
* ```image_count```: 与产品相关的图片总数
* ```badges```: 与产品相关的徽章或标签
* ```care```: 产品的护理/养护说明
* ```documents```: 与产品相关的文档
* ```facts```: 关于产品的事实或具体信息
* ```materials_description```: 产品所用材料的描述
* ```measurements```: 产品的尺寸/测量数据
* ```model_name```: 产品型号名称或标题
* ```offers```: 与产品相关的优惠或促销
* ```other_attributes```: 产品的其他属性或特性
* ```packages_description```: 产品包装说明
* ```product_series```: 产品所属系列

以及更多内容。

这是从 “Ikea products” 数据集中派生的样本子集，该数据集包含超过 <b>71.9K 条记录</b>。

可用的数据集文件格式：<b>JSON、NDJSON、JSON Lines、CSV 或 Parquet。可选将文件压缩为 .gz</b>。

数据集交付方式选项：<b>Email、API 下载、Webhook、Amazon S3、Google Cloud storage、Google Cloud PubSub、Microsoft Azure、Snowflake、SFTP</b>。

更新频率：<b>一次、每日、每周、每月、每季度，或自定义</b>。

可对提取的数据点进行数据富化：<b>按需提供</b>。

<b>[获取完整的 Ikea 数据集](https://www.bright.cn/products/datasets/ikea)</b>。

<h2>Ikea 数据集有哪些用例？</h2>

<h3>1. 定价优化</h3>
通过将类似的 IKEA 产品与品类与竞争对手进行比较，制定定价策略并实施动态定价模型。

<h3>2. 识别缺口</h3>
识别库存缺口、对特定 IKEA 产品的上升需求，以及消费者中的趋势商品。

<h3>3. 市场策略优化</h3>
利用 IKEA 数据集分析市场策略、发现关键趋势，并理解客户偏好。
