# Ikea-dataset-samples

<h2>包含 1001 款 Ikea 产品的示例数据集</h2>

![Ikea 数据集标题](https://github.com/bright-cn/Ikea-dataset-sample/blob/main/Ikea-datasets.png)

包含超过 1000 条记录的 Ikea 数据集样本。该数据集使用 <b>Bright Data API</b> 提取。

<h2>Ikea 数据集中包含的部分数据点：</h2>

* ```description```：描述 Ikea 产品的文本详情
* ```in_stock```：表示产品当前是否有货
* ```color```：产品可选的颜色或颜色选项
* ```size```：产品可选的尺寸或尺寸选项
* ```reviews_count```：产品的评论总数
* ```main_image```：产品主图的引用或链接
* ```category_url```：产品类别的 URL 链接
* ```category```：产品所属的类别
* ```category_id```：类别的唯一标识符
* ```category_tree```：产品类别的层级结构表示
* ```rating```：产品的平均评分
* ```image_urls```：产品图片的引用或链接
* ```designer```：与产品相关的设计师
* ```details```：产品的其他详情
* ```brand```：与产品相关的品牌
* ```related_products```：与当前产品相关的产品
* ```model_number```：产品的型号
* ```video_count```：与产品相关的视频总数
* ```videos```：产品相关视频的引用或链接
* ```image_count```：与产品相关的图片总数
* ```badges```：与产品相关的徽章或标签
* ```care```：产品的保养说明或详情
* ```documents```：与产品相关的文档
* ```facts```：产品的事实或具体信息
* ```materials_description```：产品所用材料的说明
* ```measurements```：产品的尺寸或测量数据
* ```model_name```：产品型号的名称或标题
* ```offers```：与产品相关的优惠或促销
* ```other_attributes```：产品的其他属性或功能
* ```packages_description```：产品包装说明
* ```product_series```：产品所属的系列

以及更多内容。

这是“Ikea 产品”数据集的示例子集，该完整数据集包含超过 <b>71.9K 条记录</b>。

可用的数据集文件格式：<b>JSON、NDJSON、JSON Lines、CSV 或 Parquet。文件还可选择压缩为 .gz 格式</b>。

数据集交付方式选项：<b>电子邮件、API 下载、Webhook、Amazon S3、Google Cloud Storage、Google Cloud PubSub、Microsoft Azure、Snowflake、SFTP</b>。

更新频率：<b>单次、每日、每周、每月、每季度或自定义</b>。

可在已提取的数据点基础上添加数据扩充：<b>按需求提供。</b>

<b>[获取完整的 Ikea 数据集](https://www.bright.cn/products/datasets/ikea)</b>。

<h2>Ikea 数据集有哪些用例？</h2>

<h3>1. 定价优化</h3>
通过将类似的 IKEA 产品及类别与竞争对手进行比较，制定定价策略并实施动态定价模型。

<h3>2. 发现缺口</h3>
识别库存缺口、特定 IKEA 产品不断增长的需求，以及消费者中的热门商品。

<h3>3. 市场策略优化</h3>
利用 IKEA 数据集分析市场策略、发现关键趋势并了解客户偏好。
